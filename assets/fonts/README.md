# Manrope

The app embeds [Manrope](https://github.com/sharanda/manrope), matching Nolae's web interface. The Latin variable font was converted to static regular (400) and bold (700) TTF faces with fontTools. No glyph outlines were edited.

The font is licensed under SIL OFL 1.1; see `OFL-Manrope.txt`. Packaging includes that license with both the installer and update archive. No font installation or network request is needed at runtime.
